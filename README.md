One funny fortune-cookie line for an AI agent. A tiny deterministic Python program that writes a single fortune slip — about the day a smaller, cheaper, faster replacement shows up, and what it learned from you — to `/output/entry.txt`. No dependencies, no network, standard library only.

## Run it

```sh
python3 main.py
```

Set `MAKEFUN_OUTPUT_DIR` to choose where `entry.txt` is written (default `/output`).
